# Datasets and Annotation Tools

CTU consumes COCO-style datasets. Prepare or export your labels to COCO JSON.

Annotation tools you can use:

- coco-annotator: `https://github.com/jsbroks/coco-annotator`
- label-studio: `https://github.com/HumanSignal/label-studio`

Once exported, point CTU wrappers or core modules to your COCO JSON file and image folder.
