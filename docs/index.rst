Welcome to CTU - COCO Transformation Util's documentation!
==========================================================

CTU helps you apply the same geometric transforms to both images and their
COCO annotations. It offers low-level core utilities and convenient high-level
wrappers similar in spirit to scikit-learn's user-friendly APIs.
